# 解説動画「絵のなかを、キャラが歩くまで（背景の絵 + VRM + ARDY）」の読み取りメモ

動画（約3分57秒、1920×1080、BGMのみ・ナレーション無し）を4秒おきに全フレーム読んで拾った内容。
左が絵、右が数値パネル。数値パネルの色が章を表す（歩道=赤、ARDY=青、階段=緑、バス停=ピンク、つま先歩き=黄）。

## 3. ARDY（NVIDIA）の公式情報（2026-10-10時点で確認）
- GitHub: https://github.com/nv-tlabs/ardy （コードは Apache-2.0。モデルの重みは別ライセンス＝ NVIDIA Open Model Agreement と表記）
- プロジェクトページ: https://research.nvidia.com/labs/sil/projects/ardy/
- 論文: https://arxiv.org/pdf/2607.08741
- 自己回帰型の拡散モデル。文章を流しながら動きを作れる。ルートの経路・ウェイポイント、全身キーフレーム、手足など一部の関節の位置/回転を制約として渡せる（＝動画の「渡した点」）。
- 履歴フレーム数は `--history_frames` で指定（動画の「つなぎ目で見せる8コマ」に対応すると思われる。動画では名前は出ない）。
- 出力は `.npz`: `posed_joints`（世界座標 `[T, J, 3]`）、ローカル/グローバル回転、ルート位置、足の接地、`fps`、`text`。BVHは出ない。
- Core骨格のモデルは 20 FPS（動画の20コマ/秒と一致）。Unitree G1 版は 25 FPS。
- 導入: Python 3.11、PyTorch ≥ 2.4（CUDA版）、`pip install -e ".[all]"`。文章エンコーダに Meta-Llama-3-8B-Instruct（Hugging Faceで利用申請が必要、`hf auth login`）。GPU目安: RTX 4090 で確認、エンコーダだけで約14GB VRAM。
- 生成例: `python scripts/generate.py "A person walks forward." --model core --duration 8.0 --seed 0 --output walk` ／ 表示: `python scripts/visualize.py outputs/walk.npz`
- 制約ファイルは `--constraints` で渡す。形式は公式READMEを参照（このスキルの作成時には中身を確認していない）。
