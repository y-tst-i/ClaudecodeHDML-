# Picture Walk — 一枚絵の中を VRM キャラが歩く

`toolkit/`（picture-walk-vrm-ardy）の方法を、three.js で動く形にしたもの。
3D背景は作らず、絵に合わせた「見えない床」の上に VRM を立たせて歩かせる。

```bash
npm run dev            # http://localhost:5173/walk/          … ループ再生
                       # http://localhost:5173/walk/?grid=1   … 1mマス目＋身長1.45mの目印（1-D の確認）
npm run probe -- --page /walk/ 2 6 10 13.8         # 指定秒を撮る → out/probe/sheet.png
npm run probe -- --page /walk/ --q nozoom=1 9 10   # 最後の寄りを止めて撮る
node scripts/render.mjs --page walk/               # out/walk.mp4（14秒・30fps）
```

## ファイル
| ファイル | 役割 |
|---|---|
| `src/picture.js` | 絵ごとの値（カメラ・太陽・日陰のしきい値・通り道・身長）。別の絵ではここを書き換える |
| `src/camera.js` | toolkit の Camera と同じ約束で three.js のカメラを作る。主点が中心でない絵・切り出しにも対応 |
| `src/gait.js` | 仮の歩き（足跡プランナ）。ARDY の動きが来るまでの代わり |
| `src/rig.js` | 腰・脚の二関節IK・腕・指・頭を VRM の正規化ボーンに載せる |
| `src/shade.js` | 絵の明るさで日向/日陰（キャラ）と、見えない床の影（乗算） |
| `toolkit/` | 受け取ったツールキット（SKILL.md・計算スクリプト・動画メモ）そのまま |

素材：背景 `public/textures/walk/sidewalk.png`（Codex 画像生成）、キャラ `public/models/sample.vrm`
（pixiv「VRM1_Constraint_Twist_Sample」。再配布・改変・商用可、クレジット不要と VRM のメタに記載）。

## この絵で測った値（1. カメラ推定の記録）
| 項目 | 値 | どう決めたか |
|---|---|---|
| 消失点 | (643, 380) | 歩道の縦目地が集まる点を、目地の暗い線の揃い具合で探索 |
| 向き（yaw） | 0° | 横目地が絵の中で水平 → カメラは道に正対。消失点が左にあるのは **レンズが横にずれた絵**（AI生成の絵ではよくある）とみなし、主点 cx=643 にした。toolkit の式のまま中心 768 を使うと右向き6.2°になり、格子が右上がりに傾いて合わなかった |
| 傾き（pitch） | 下向き 6.61° | 消失点の行 380 と主点 cy=512 から |
| 横の画角 | 68°（F≈1139px） | **仮定：タイルは正方形**。35mm（54.4°）だとタイルが縦長1.32倍になった |
| カメラの高さ | 1.356 m | **大きさの基準：タイル 35cm 角**（手前のタイル幅 151px @ 行969 から） |
| 確認 | 0.35m 格子が手前の目地（行 969 / 900）と縦目地に重なる。1/(v−380) が行ごとに等間隔 |
| 歩道 | 塀 x≈−1.85m 〜 縁石 x≈+1.3m（幅 約3.1m） | 床の逆投影 |
| 太陽 | 絵の左上の光源 (420, 0) の方向。高さ17°、手前やや右へ影 | |
| 日陰/日向 | 歩道の輝度 日陰≈0.42 / 日向≈0.82 → しきい値 0.50〜0.68。影の色比 (0.40, 0.54, 0.76) | 歩道の画素の分布 |

決めた値（仮定）は2つ：**タイルは正方形・35cm角**。どちらかを変えると全メートル値が変わる。

## 描き方の要点（5. アニメ塗り）
- キャラ：MToon のまま。フラグメントごとに「太陽の反対方向へたどって床に当たった所の絵の明るさ」を読み、日陰なら影の色比をかける。木漏れ日の形がそのままキャラに乗る。
  ただし **頭（顔・目・髪）は頭の中心1点で判定**（顔に斑点が乗るとマスクに見えたため）。
- 床：見えない板（ShadowMaterial を乗算に改造）。**絵が日向の所にだけ**キャラの影を落とす（日陰に二重の影を作らない）。
- 足元：足が床に近いほど濃くなる小さな接地影。
- 逆光の縁取り（MToon リム、暖色）と、太めの焦げ茶の輪郭線。
- 最後の寄りは「絵の切り出し範囲を狭める」だけ。カメラは同じなので合成はずれない。

## 時間の純関数について
- 歩き・まばたき・表情はすべて t から計算。
- ばね骨（髪・服の揺れ）は前フレームの状態を持つので、**毎フレーム「直前1秒」を同じ手順でリセット→計算し直す**。
  これで seek(t) の結果は t だけで決まる（書き出しとWebで同じ絵）。

## ARDY の動きに差し替えるとき（次の段階）
今の `gait.js` は ARDY の代わり。ARDY は GPU（RTX 4090 目安・Llama-3-8B-Instruct の利用申請）が要るので、このクラウド環境では動かせない。
1. GPU のある PC で `toolkit/HANDOFF.md` の手順 1〜5（生成 → `foot_correct.py inspect` → `flatten`）
2. できた `.npz` の `posed_joints`（[T, J, 3]、20fps）を JSON に書き出して `public/` に置く
3. `rig.js` の `apply()` に、gait の代わりに「腰の位置・左右の足首と爪先の位置」を毎フレーム渡す（IK 部分はそのまま使える）。
   上半身は関節位置から骨の向きを作る（腕・背骨・首）
