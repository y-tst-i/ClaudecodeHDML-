# YOHI の世界 — 設計書

この世界で新しい場面・素材・音を作るときは、まずここを読む。Codex に素材を頼むときは、この内容を依頼文に入れる。
迷ったら「ブラウン管の部屋」（yohi/room.html）が基準。

## 1. ひとことで
**夜の倉庫。積み上がったブラウン管の光だけが部屋を照らす。そこにストリート（スプレー・ステッカー）とモード（リソグラフ・黒とオレンジ）が混ざる。**

## 2. 色
| 役割 | 色 | 使いどころ |
|---|---|---|
| 闇（背景の基本） | `#020203` | 部屋・余白。真っ黒ではなく、ほんの少し青みのある黒 |
| 蛍光（光の色） | `#C7FFDB` 前後（緑がかった白） | ブラウン管の光・発光する文字・光が部屋を照らす色 |
| 差し色 | `#FF481B`（オレンジ） | 1画面に1か所だけ強く。光源（ネオン・ランプ）、サイン、マフラーなど |
| インク | `#0F0E0F` | 印刷の黒ベタ |
| 紙 | 生成り（riso_paper の色） | 印刷・ポスター |

- 画面の8割は暗い。明るいのは「光っている物」だけ
- オレンジは「たくさん使う」と安くなる。小さく・強く

## 3. 質感（すべて写真素材＋コード）
- ブラウン管：ふくらんだガラス、走査線、指紋、映像のにじみ、端で色がずれる
- テレビの外装：黒〜こげ茶の樹脂、色あせた木目。角が擦れている
- 床：濡れたコンクリート。光が1つずつにじんで映り込む
- 印刷：リソグラフの粒、黒ベタの中の繊維の抜け、版ずれ
- ストリート：コンクリート壁、スプレーの芯と飛沫、垂れ
- **使わない**：素の CG 質感（Normal・Depth・のっぺりした単色の面・素のグラデーション）

## 4. 光
- 光源は「世界の中にある物」だけ（画面・ネオン・ランプ）。どこからともなく照らす光は使わない（使うなら外装が見える最低限）
- 光るものだけがにじむ（ブルームのしきい値は高め）
- 明るすぎる所はなだらかに頭打ち。**真っ白に飛ばして形を消さない**（衝撃の瞬間も）
- 仕上げは全場面共通：にじみ → 端の色ずれ → 周辺減光 → フィルムの粒 → レンズの埃

## 5. 文字と形
- ロゴ3種：A（細長いセリフの名前＝モード）／B（スプレーのタグ＝ストリート）／D（Y の幾何学マーク）
- UI：JetBrains Mono 12px/16px・太さ600・英字の字間0・8の倍数・ボタン高さ32px・角丸なし・ホバーは色だけ
- UI の言葉は動詞1語（HOLD / DRAG / CLICK / MOVE）。説明文は出さない

## 6. 動きと音
- 120BPM。大事な瞬間は拍の頭、細かい動きは16分音符に揃える
- 型は **「溜めて → 一瞬切って → 落とす」**（長押しで溜まる → 衝撃）
- 離したら戻る（逆再生でほどける）。操作に必ず手応え（音・光・揺れ）を返す
- 音はコードで合成してファイルに書き出し、操作に合わせて鳴らす。BGM がある場面は16分音符に揃える
- 監督の好み（これまでの FB）：迫力・音ハメが好き。インタラクティブな遊び・驚き・「事件」（キャラが世界をいじる出来事）のアイデアは GPT（scripts/codex.sh review）にも出させる。地味・チープ・よくある感じ・わかりにくいは嫌い。雫のポタッ音は不要

## 7. やってはいけない
- 実在のブランド・キャラクター・ロゴに似せる
- 同じ絵の繰り返し（壁紙に見える）→ 1つずつ範囲・色味・動きを変える
- 真っ白・真っ黒に飛ばして形を消す
- UI を派手にする（派手なのは場面だけ）

## 8. キャラクター：電気のけもの
- 設定画：`yohi/assets/chara/mon_b_spark.png`（Codex）／3D：`yohi/src/chara/creature.js`（コードで組み立て）
- 黒〜こげ茶のソフビ。光るのは目・ほっぺ・耳の先・胸のしま2本（ミント）。しっぽの先だけオレンジ（差し色はここ1か所）
- 光る所は「色を黒・発光だけ」にする（照明で白っぽくならない）。暗い部屋では光を弱めに（ブルームで体が霞む）
- 性格：ふだんは落ち着いて少し強気。電気が溜まると震えて耳を倒し、満タンで跳ねて喜ぶ
- 動きは (t, power, sinceImpact, look) だけで決まる。置き場所は外側の入れ物で決める（キャラ自身の高さは跳ねる動きに使う）
- 監督の評価（v1）：「初動としては良い」。設定画より頭が小さめ・体が短め
