# Codex で画像素材を作る

ユーザーの ChatGPT（Plus）アカウントでログインした Codex CLI に画像を生成させ、PNG として保存する。
使った分はユーザーの Codex の利用枠を消費するので、作る枚数は依頼に必要な分だけにする。

## 1. ログイン（セッションごとに1回）

```bash
bash .claude/skills/codex-images/codex-images.sh login
```

- `LOGGED_IN` と出たら、そのまま 2 へ進む
- そうでなければ、出力にある **URL（https://auth.openai.com/codex/device）とコード（例 ABCD-12345）** をユーザーに伝え、
  「URLを開いて ChatGPT でサインインし、コードを入れて許可してください」と頼む。コードは15分で切れる
- 承認を待つときは、`LOGIN_PID` のプロセスが終わるまでを Bash の run_in_background で待つ（終わると通知が来る）：
  `while kill -0 <LOGIN_PID> 2>/dev/null; do sleep 5; done; codex login status`
- ログインはこの環境（コンテナ）の中だけに保存される。環境が消えたら、次のセッションでまたログインする
- ユーザーのパスワードや API キーを聞かない。コードは他人に教えないよう伝える

## 2. 依頼文を書く

作業用フォルダ（スクラッチパッドなど）に依頼文ファイルを作る。必ず次を入れる：

- 何の素材か（用途・雰囲気・画風・配色）
- **ファイル名の一覧**（英数字の .png。例 `bg_01.png`、`prop_phone.png`）と、それぞれに何を描くか
- 縦横の大きさ（縦型動画の背景なら 1024×1536）
- 背景を透明にするもの（小物・ステッカー・キャラ）
- 入れてはいけないもの（文字・ロゴ・透かし・実在の人物やキャラクター）

## 3. 生成する

```bash
bash .claude/skills/codex-images/codex-images.sh generate <出力フォルダ> <依頼文ファイル> [参考画像 ...]
```

- 1枚 30秒〜1分ほどかかる。枚数が多いときは run_in_background で動かし、終わりの通知を待つ
- 同じ人物・キャラをそろえたいときは、設定画などを参考画像として渡す
- 終わったら、出力の「作った画像」の一覧を確認し、Read で中身を見て、依頼どおりかを確かめる。
  ダメなものだけ、依頼文を直して作り直す
- できた画像をユーザーに見せる（SendUserFile）か、プロジェクトの素材フォルダへコピーする

## うまくいかないとき

- `NOT_LOGGED_IN` → 1 のログインからやり直す
- 画像ができない・途中で止まる → 生成ログ（codex の出力）の最後を見て、枚数を減らして再実行する
- 利用枠の上限に達したというエラー → ユーザーに伝えて止める（時間をおくと戻る）
