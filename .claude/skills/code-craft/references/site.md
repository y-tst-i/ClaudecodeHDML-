# サイト（LP・ポートフォリオ・体験型）

## 構造の型
- デザイントークン（色・書体・余白・角丸・影・モーションの速さ）を CSS 変数に集約
- セクション表（ID・見せたいこと・肝・操作・FB）をデータとして持つ
- 1セクションに肝は1つ。ファーストビューは「一番言いたいこと」と「次にすること」だけ

## 撮り方
```bash
node .claude/skills/code-craft/scripts/shoot.mjs http://localhost:5173 --viewports desktop,mobile --full --out out/shots/v1
```
- desktop と mobile を必ず両方撮る。モバイルで崩れていないサイトの方が少ない。
- 横はみ出しは shoot.mjs が数値で検出する。
- インタラクション（ホバー、開閉、遷移アクション）は Playwright で操作した状態も撮る（`page.hover` → screenshot など、プロジェクトに小さなスクリプトを置く）。

## 体験型サイト
- スクロール連動は行き過ぎ・戻りで体験が崩れやすい。シーンごとの**遷移アクション**にして、クリアで次へ進める。
- 案内UIは静かに：小さな半透明ラベルが細い線で操作する場所を指し、残りの回数・距離だけを出す。
- 自動操作のスモークテスト（最初から最後まで操作して完走できるか）を用意し、UIを触るたびに回す。

## UIの案を出すとき
- いきなり3案出すなら、方向性を変える（情報量・トンマナ・配置）。同じトンマナの色違い3案は意味がない。
- 社内レビューで「AIっぽい」と言われたら、まずシーンとUIのトンマナが同じになっていないかを疑う。
- 削りすぎて次の行動が分からなくなったら戻す。字幕型・ラベル型など2案まで絞って比較する。

## 実戦で学んだこと（YOHI 体験型サイト・ブラウン管の部屋）

- **公開先の CSP**：claude.ai などの公開先では `data:` URL への `fetch` が止められる。埋め込んだ音や素材は `atob` で直接バイト列にする。テストのサーバーにも `content-security-policy: connect-src 'self'` を付けて同じ条件で通す（付けないとすり抜ける）。
- **音は「ファイル＋コードで鳴らす」**：効果音はコードで合成して1つずつ書き出し、操作に合わせて鳴らす。BGM がある場面では次の16分音符まで待って鳴らし、絵の切り替えも同じ瞬間にする（雑に触っても音がハマる）。AudioContext はページを開いた時点で作って decode まで済ませ、最初の操作で `resume()`。
- **2D → 本物の3D で質が一段上がる**：写真素材（Codex 生成）の外装・床・壁、画面には映像版のシェーダーを RenderTarget で映す、共通の仕上げ（ブルーム → レンズ：色ずれ・周辺減光・粒・埃 → OutputPass）。濡れた床は Reflector の鏡像を床の凹凸でゆらして縦にぼかし、足し算で重ねる。
- **自分で撮って見て直す回数がそのまま質**：初回は「床がのっぺり」「衝撃で真っ白」「全画面が同じ絵で壁紙っぽい」が必ず出る。光を足すより、明るすぎる所をなだらかに頭打ちにし、テレビごとに映す範囲・色味・ロールを変える。
- **重さは自動で調整する**：1コマの時間を測り（45コマか1.5秒の早い方で判定）、解像度 → 重い処理（映り込み）の順に1段ずつ下げる。上げ直さない。今の段階を小さく表示する。GPU の無いテスト環境は「遅いパソコン」の再現に使える（LOW まで下がることをテストで確かめる）。
- **テストは時間ではなく状態で待つ**：遅い環境では1コマ1秒かかる。「0.8秒待って比べる」は落ちる。「値が実際に下がるまで待つ」にする。スクリーンショットは遅いので、判定のあとに撮る。

## 実戦で学んだこと（YOHI 2場面：けもの・路地・飛び込み）

- **キャラは「設定画（Codex）→ コードで組む → 三面を並べて見比べる」を回す**：1回目は必ずズレる（眉毛のようなまぶた、竹馬の足、見えない胸のしま）。正面・横・後ろを設定画と同じ並びで撮って横に置くと、どこが違うか一目でわかる。
- **光る部品は「色を黒・発光だけ」**：MeshStandard の色を明るくすると照明で白っぽくなる。暗い場面ではブルームで体が霞むので、発光は弱めにする（glowScale）。黒目は MeshBasic の真っ黒（周りの光を拾うと赤く濁る）。
- **暗い場面の黒いキャラには後ろから細い光**：輪郭が闇に溶けると、目と胸の模様だけが浮いて「大きく笑った顔」に見える。リムライト＋体の向き（横向き）で解決。
- **置き場所と動きの入れ物を分ける**：キャラ自身の position.y を跳ねる動きに使うなら、置き場所は外側の Group で決める（でないと床に落ちて隠れる）。
- **場面転換は「同じ要素でつなぐ」**：画面に飛び込む → 波紋 → ブラウン管の画素が拡大して視界を埋める → 画素が縮んで次の場面。蛍光体の縞は明るさを頭打ちにしてから掛ける（白飛びに掛けるとピンクに濁る）。線が画面の点より細い間は3色の平均色にする（モアレ防止）。
- **遊びの完成は「操作の色＝結果の色」**：吹いたスプレーと完成するタグは同じ色。完成したら、はみ出した跡は垂れて流れ落ち、結果だけが残る（気持ちよさが一番出る）。
- **重いページの撮影は準備完了を待つ**：読み込み完了（networkidle）のあとも素材とシェーダーの準備に時間がかかる。`__seek` が出るまで待ってから撮る。
