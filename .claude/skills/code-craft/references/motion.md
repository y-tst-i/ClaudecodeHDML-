# 映像（モーショングラフィックス）

## 構造の型
- `config`：尺・BPM・FPS・解像度・テーマカラー・乱数の種
- `timeline`：シーンの時間割と転換（＝絵コンテのコード版）。グローバル時刻 t からシーンとローカル時刻を決める
- `scenes/*`：1シーン1ファイル。`update(t)` は **t だけ**で画が決まる純関数
- `cuts`：カット表データ（ID・尺・動き・Webでの操作・FB）
- 書き出し：ページが `window.__seek(t)` を公開し、ヘッドレスブラウザで1フレームずつ seek して PNG → ffmpeg

`Math.random()` / `Date.now()` / 前フレームの状態への依存は禁止（乱数は seed 付き、例：mulberry32）。これが崩れると、書き出した映像とWeb版で画がズレ、撮影比較もできなくなる。

## 撮り方
```bash
node .claude/skills/code-craft/scripts/shoot.mjs http://localhost:5173/?mode=render --mode time --times 0.5,2,4.75,5,5.25,8 --out out/shots/v3
```
- カットの**はじめ・おわり**と、**転換の中間**（50%付近）を必ず撮る。破綻は中間に出る。
- 書き出しの確認は mp4 の尺（`ffprobe`）と、数フレームの目視。

## テンポ
- 音楽を先に決め、BPMを config に入れて切り替えをビートに合わせる。間延びしたら尺を詰めて BPM を上げる（例：60秒/144BPM → 50秒/174BPM）。
- カメラは「止まって見せる → ease-in-out で動く」の緩急。ずっと動き続けると何も見えない。
- 太いタイポは画面に貼るだけでなく、3D空間に置く・画面を覆って転換に使う。

## 質感
- 素のNormal/Depth/Clayは未完成に見えやすい。クローム、トゥーン、リムライトなど「完成した質感」を優先。
- 気に入った要素（色、リム）は次のシーンへ引き継いで世界をつなぐ。
- 実写テクスチャ（ヒビ・網点・汚れ・ブラウン管の蛍光体）を重ねてCGっぽさを消す。ただし重ねすぎると変な模様になる（素材のせいで輪郭に謎の模様が出た例あり）。

## 映像 → 体験型Web
同じシーンのコードを使い、時刻 t をユーザー操作で進める。スクロール量で t を進めると行き過ぎて体験が崩れるので、シーンごとの「遷移アクション」（クリックN回、ドラッグで歩く、クリックで割る）にする。ループ区間で待ち、クリアしたら次の区間まで再生する。詳しくは `site.md`。
