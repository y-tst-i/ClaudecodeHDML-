# センス：緩急・抜け・作り込み

## 原則
1. **緩急**：見せ場（肝）と抜く所を決める。全部を同じ熱量・同じトンマナで作ると、一体感はあっても視線が迷う。これが「AIっぽい」の正体のひとつ。
2. **シーンが派手なら UI は静かに**。ただしミニマル＝手抜きではない。字間・余白・線の太さ・ホバーまで徹底的に作り込む。
3. **一続きの世界**：テーマカラーや質感は背景まで揃える。途中で別の世界に見えたら直す。
4. **未完成っぽいものは削る**。かっこいいものを目立たせるには、そうでないものを消すのが早い。
5. **大量の要素は1つの式で動かす**（破片・パーティクル・リスト）。別々に作ると層が分かれて見える。
6. **ミニマルにしすぎない**：情報を削りすぎると「次に何をすればいいか」が伝わらない。必要な情報（残り回数・距離・現在地）だけは残す。

## 既定のUIルール（プロジェクトの CLAUDE.md にルールがあればそちらを優先）
- 余白・サイズは 8 の倍数
- ボタンの高さ 32px、角丸なし、ホバーは文字色・背景色の変化だけ（浮かせない、影を足さない）
- UIの英字は字間 0（文章中の英字は読みやすさ優先）
- 操作の案内は、半透明の小さなラベル＋細い線で場所を指し、残りの回数や距離だけを示す

## AIっぽさのサイン（自己レビューで1つでも当てはまれば直す）
- 黒背景＋ネオン＋グリッチ＋パーティクル、紫〜青のグラデーション、ぼかした丸
- 同じ大きさのカードが3枚並ぶ／全部が中央揃え／全部の見出しが同じ強さ
- 絵文字アイコン、「Unleash」「Elevate」「次世代の」のような中身のない言葉
- どこにも「肝」がない（スクリーンショットを縮小して、最初に目が行く場所が1つに決まるか）
- 効果を全部の要素にかけている（影・グロー・アニメーションの付けすぎ）
- 仮テキスト、Lorem ipsum、ダミー画像が残っている

## 撮らないと気づけない不具合（チェックリスト）
- [ ] 文字が3Dオブジェクトや他の要素の裏に隠れていない
- [ ] ラベル・見出しが画面端で切れていない（各ビューポートで）
- [ ] 白飛び・黒つぶれ（強すぎるスペキュラ、ライトの当てすぎ）がない
- [ ] `[hidden]` や `display:none` が他のCSSで上書きされていない
- [ ] 横スクロール（はみ出し）がない
- [ ] 転換の中間フレーム（50%付近）が破綻していない
- [ ] 操作の組み合わせ（ドラッグ後のクリック、連打、戻る）で状態が壊れない
- [ ] モバイルで文字が小さすぎない（本文 14px 以上目安）

## 良いFBの形（自分のFBも、ユーザーへの質問もこの形で）
**何が** ／ **なぜダメか** ／ **何を基準に直すか**
- ✕「ガラスが変」 → ○「最後に割れるガラスがチープ。C03 のガラスの質感に揃える」
- ✕「暗い」 → ○「Cはのっぺり明るく奥行きがない。Bは台座が見えず浮いて見える。Cをベースに、Bの天窓スポットの陰影だけ合わせる」

## コードで描く絵は「写実」を狙わない（学び）
- ブラウザで計算した立体・質感で**写実を目指すと、どれだけ作り込んでも「安いCGデモ」に見える**。写実が要るなら写真（画像生成を含む）を使い、コードは動き・文字・転換に専念する。
- コードで絵を描くなら**様式化（イラスト調）に振り切る**。参考：re-presentation.jp の plume. デッキは、3Dのスマホをトゥーン塗り＋太い輪郭線で描き、輪郭線を**1秒12コマでわずかに揺らして**手描きの線が「ふるえる」感じを出し、紙の粒子とゆるい図形（ブロブ）を重ねている。
- 画風・色・書体・注記の線まで**1つの絵柄の規則**で統一する。1枚ごとに背景色を変えて章のリズムをつくり、見出しは「黒の1行目＋アクセント色の2行目」のように**型を決めて**くり返す。
- 叩きつける・大きくするより、**余白と抑えた文字の太さ**の方が上品に見える場面が多い。派手さは絵に任せ、文字は静かに。
