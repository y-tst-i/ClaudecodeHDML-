# スライド

## 構造の型
`assets/slides-template.html` をコピーして始める（1枚 = 1920x1080 の `<section data-slide>`、`window.__slides` で送り、印刷CSSでPDF化）。
トンマナは `:root` のトークンだけで決める。

## 作り方
1. まず**1枚1文**の構成表を作る（「このスライドで言いたいこと」を1文で）。文が書けないスライドは不要。
2. 各スライドの「肝」を1つ決める（大きな数字、1枚の画、1つの図）。それ以外は小さく、少なく。
3. 情報の種類ごとにレイアウトの型を3〜5個に絞って使い回す（表紙／見出し＋本文／大きな数字／画像全面／比較）。毎回違うレイアウトにすると散らかる。
4. 図はSVGかHTMLで描く（後から直せる）。

## 撮り方
```bash
node .claude/skills/code-craft/scripts/shoot.mjs deck/index.html --mode slides --pdf --out out/shots/v1
```
- `sheet.png` で全体を一覧し、**縮小しても各スライドの肝が分かるか**を見る。
- 文字のはみ出し、行末の1文字だけの行（泣き別れ）、詰め込みすぎを直す。
- 提出物は `deck.pdf`。

## AIっぽいスライドのサイン
- 全スライドが「見出し＋箇条書き3〜5個」
- アイコン＋短文のカードが3枚並ぶ
- 抽象的な言葉だけで数字・固有名詞・具体例がない
